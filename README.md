## 📖 Overview
<a id="overview"></a>

**NAPS2** is a free and open-source document management software designed for efficient document scanning and PDF conversion. Compatible with a variety of scanners—including popular brands such as Canon, Brother, HP, Epson, and Fujitsu—NAPS2 simplifies the setup process with quick user profile creation in under two minutes. The latest version ensures users enjoy full functionality with customizable scanning preferences and an Optical Character Recognition (OCR) feature for swift text searches, all while maintaining a small PDF size.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **User-Friendly Setup** — Create a user profile in less than two minutes for quick access to scanning tasks.
- **Customizable Scanning Preferences** — Set DPI, page sizes, and choose between WIA and TWAIN drivers, with WIA as the default.
- **Document Preview** — Preview scans before saving to ensure quality and accuracy.
- **Page Management** — Effortlessly rearrange, rotate, and trim pages to meet your document needs.
- **Optical Character Recognition (OCR)** — Supports multiple languages, allowing for easy text searches in scanned documents.
